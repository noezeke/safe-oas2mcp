# Windsurf

Configure `safe-oas2mcp` as an MCP stdio server.

Command:

```bash
safe-oas2mcp
```

Arguments:

```text
serve
D:/corevo/openapi2mcp/examples/todo/openapi.yaml
```

For authenticated APIs, add:

```text
--config
D:/corevo/openapi2mcp/safe-oas2mcp.config.yaml
```

Run inspect first:

```bash
safe-oas2mcp inspect D:/corevo/openapi2mcp/examples/todo/openapi.yaml
```
